# Odin Recipes 🍽️

Welcome to **Odin Recipes**, my first website project built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

This is a simple multi-page recipe website built using HTML. It features different recipes with descriptions, ingredients, cooking instructions, and images.

## 🍴 Recipes

1. **Chicken Biryani** – A flavourful rice dish cooked with aromatic spices and chicken.
2. **Masala Dosa** – A crispy South Indian dosa filled with spiced potato masala.
3. **White Sauce Pasta** – Creamy pasta prepared with white sauce, herbs, and seasonings.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/ChadaSriSai0407/odin-RECIPES.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Select a recipe to explore its ingredients and instructions.
